# FuelWise Data Sources & Telemetry Audit Log

This document records the exact provenance of all data sources used across the FuelWise platform, strictly fulfilling Ground Rule 1 (**No fabricated data, anywhere**) and Section 3 (**Real Data Sources**).

---

## Data Source Audit Matrix

| Physical Quantity | Live Network Source Integrated | Status in Current Build | Documented Fallback Mechanism | UI Disclosure Label |
|---|---|---|---|---|
| **Distance & Route (D)** | **OSRM Driving API** (`router.project-osrm.org`) & OpenStreetMap Nominatim Geocoding | **LIVE & ACTIVE** | User manual entry of distance in km | `[OSRM Live Routing Network]` or `[Manual Route Estimate]` |
| **Average Speed (V)** | Derived from OSRM route duration & distance ($V = D / t$) | **LIVE & ACTIVE** | User enters expected cruising/avg speed in km/h | `[Computed from Route Geometry]` or `[Manual Speed Estimate]` |
| **Traffic Intensity (T)** | TomTom Traffic Flow API (when `TOMTOM_API_KEY` set) | **CONFIGURABLE** | 4-level calibrated scale (Free: 0.10, Light: 0.35, Moderate: 0.65, Heavy: 0.95) | `[TomTom Live Traffic]` or `[Documented 4-Level Scale]` |
| **Road Gradient (G)** | **Open-Elevation API** (`api.open-elevation.com`) sampled along route waypoints | **LIVE & ACTIVE** | Omitted from equation ($G = 0$) | `[Open-Elevation Public API]` or `[Gradient Not Available for this Route]` |
| **Fuel Price (P)** | Daily retail feed benchmark / Live Oil Marketing Companies feed | **LIVE & ACTIVE** | User manual entry with timestamp | `[Public Benchmark]` or `[Self-Reported User Price]` |
| **Real-Time GPS & Speed** | Browser/Phone **HTML5 Geolocation API** (`watchPosition`) | **LIVE & ACTIVE** | Manual trip logging form | `[HTML5 Geolocation High-Accuracy Telemetry]` |
| **Hard Accel / Brake Events (A)** | Browser/Phone **DeviceMotionEvent** (Accelerometer) | **LIVE & ACTIVE** | Manual event count entry | `[DeviceMotion Accelerometer Live Sensor]` |
| **Idle Duration ($t_{\text{idle}}$)** | Browser Timer tracking time with GPS speed $< 3$ km/h | **LIVE & ACTIVE** | Manual idle minutes entry | `[Live Idle Detection Timer]` |

## Strict Compliance Rules Followed

1. **No Simulated Regression**:
   All calibrated coefficients are generated by running Ordinary Least Squares (OLS) via `src/lib/regression.ts` on actual stored rows in the `trip_logs` SQL table.
2. **Threshold Enforcement**:
   If a vehicle has fewer than 8 logged trips, the platform refuses to claim a calibrated model and visibly presents `POPULATION_BASELINE_COEFFICIENTS` with:
   `"Need X more trips before we can calibrate your personal model"`.
3. **No Hidden Constants**:
   Whenever a fallback or default price is used, it is flagged with a prominent badge in the user interface.
4. **Transparent Unit Tracking**:
   Every database column, API payload, and UI metric explicitly designates its physical unit (`km`, `km/h`, `L`, `km/L`, `min`, `kg`, `INR/USD/EUR/GBP`).
